# T5 fine-tuning

QLoRA fine-tuning of Qwen3.5-27B on T5 (Color Distribution), the paper's task-specific fine-tuning
study (Appendix "LoRA fine-tuning").

## Steps

```bash
pip install -r requirements.txt

# 1. fine-tuning pool: 900 objects from the voxel generator with a different seed
cd ../generator
python -m bed_generator --out bed_voxels_ft --n 900 --seed 100
python -m bed_generator.build_tasks --samples bed_voxels --finetune-samples bed_voxels_ft --out bed_dataset
cd ../finetune

# 2. train and merge the adapter (see train.py --help for data-parallel training)
python train.py --dataset ../generator/bed_dataset/T5_finetune --output-dir t5_lora
python merge.py --adapter t5_lora --output-dir qwen3.5-27b-t5-merged

# 3. evaluate on the benchmark's T5 (test set) with the harness, Non-Thinking, 5 runs per variant
vllm serve qwen3.5-27b-t5-merged --port 8000 --tensor-parallel-size 1 --gdn-prefill-backend triton
cd ../harness
python -m bed_eval run --task T5 --variant color      --mode non_thinking --model qwen3.5-27b-t5-merged \
    --api-url http://localhost:8000 --dataset ../generator/bed_dataset --runs 5 --out results_ft
python -m bed_eval run --task T5 --variant color_axes --mode non_thinking --model qwen3.5-27b-t5-merged \
    --api-url http://localhost:8000 --dataset ../generator/bed_dataset --runs 5 --out results_ft
python -m bed_eval score results_ft
```

## Setup

| | |
|---|---|
| Data | train: pool objects 0–799; validation: 800–899; test: the 100 benchmark objects (`T5_color`, `T5_color_axes`) |
| Input / target | the two default color views and the Non-Thinking T5 prompt / `{"answer": {color: count}}` |
| Base model | Qwen/Qwen3.5-27B, 4-bit NF4 with double quantization, bf16 compute; vision encoder frozen |
| LoRA | r = 16, α = 32, dropout 0.05, on q/k/v/o and gate/up/down projections |
| Training | AdamW, peak LR 2e-4, cosine schedule, 10% warmup, weight decay 0.01, bf16, gradient checkpointing, max length 4096, batch 1 × 8 accumulation, 3 epochs |
| Selection | validation loss every 50 steps; the best checkpoint is kept |

The loss covers the whole chat sequence (labels are the input ids), as in the paper's run.

## Training pool

The pool is generated by `../generator` with `--seed 100` and the generator's default coloring, the
same 12-color, luminance-paired palette as the benchmark. `build_tasks.py --finetune-samples` refuses a
pool whose color palette differs from the benchmark's or that contains a benchmark object (same blocks and
colors).

## Verification

The paper's adapter was trained with `train.py --ddp` on 4 x RTX 3090 (`accelerate launch --num_processes 4`, `--grad-accum 2`, `NCCL_P2P_DISABLE=1`); the best checkpoint was the last one (step 300). Evaluated with `../harness` (Non-Thinking, 5 runs): T5 color 68.6 ± 0.5% EM (MAE 0.033, RMSE 0.182), color + axes 66.8 ± 1.8% (MAE 0.036, RMSE 0.191).
