# BedBench project page

Source of the project page for *Where Do Vision Language Models Fail at 3D Reasoning?*, served by GitHub Pages at
https://leduckhai.github.io/BedBench/. The code and benchmark live on the [`main`](https://github.com/leduckhai/BedBench/tree/main) branch; the dataset is on [Hugging Face](https://huggingface.co/datasets/leduckhai/BedBench).

`index.html` is self-contained (fonts inlined); `static/` holds the figures, logos, and the Try-it question sets.
